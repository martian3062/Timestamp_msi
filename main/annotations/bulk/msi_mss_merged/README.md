# MSI MSS merged export

This folder contains merged cBioPortal colorectal sample-level rows with usable MSI/MSS-style labels.

Files:
- bulk_msi_mss_sample_merged_compact.csv
- bulk_msi_mss_sample_merged_full.csv
- bulk_msi_h_only.csv
- bulk_mss_only.csv
- bulk_msi_mss_summary.json

Normalization used:
- MSI-H: MSI, MSI-H, MSI-high, Instable
- MSS: MSS, Stable
- Excluded: MSI-L, Not Evaluable, Inconclusive, Indeterminate, Do not report
